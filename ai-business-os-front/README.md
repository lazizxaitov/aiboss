# Фронтенд ИИ Бизнес ОС

Фронтенд для ядра ИИ Бизнес ОС. Интерфейс показывает единое ядро данных, миграцию СмартАпп, бизнес-модули и будущую панель управления ИИ.

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev
```

Открыть в браузере:

- `http://localhost:3000`

## Что есть в проекте

- Главный экран с ядром данных и миграцией СмартАпп.
- Разделы продаж, финансов, маркетинга, склада, Телеграм, сигналов, сводки руководителя и рекомендаций.
- Настройки платформы.

## Полезные команды

```bash
npm run lint
npm run build
```
